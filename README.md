# Doña Leonor · Paraíso Oaxtepec

Landing estática construida a partir del contenido disponible en la exportación de WordPress.

## Publicar en GitHub Pages
1. Sube `index.html`, `styles.css`, `script.js` y la carpeta `assets/` al repositorio.
2. En GitHub: Settings > Pages.
3. Selecciona la rama `main` y `/ (root)`.
4. Guarda.

## Cambios rápidos
- Teléfono: busca `55 1111 1111` en `index.html`.
- Fecha: busca `10 de octubre de 2026`.
- Fotos: sustituye los archivos dentro de `assets/` conservando sus nombres, o cambia las rutas en `index.html`.
- Ubicación: cambia el enlace del botón "Ver Oaxtepec en el mapa".

## Nota sobre las fotos
La exportación XML de WordPress contiene referencias a los archivos multimedia, pero no incluye físicamente todas las imágenes. Esta versión usa los recursos que estaban disponibles en la conversación.
